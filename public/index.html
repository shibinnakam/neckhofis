📡 ESP8266 HTTP Target

Ensure your ESP8266 SERVER_URL points to this server's /tempstore endpoint:

const char* SERVER_URL = "https://neckhofis.onrender.com/tempstore";

For local WiFi testing on the same network, replace with your laptop's local IP (e.g., http://192.168.1.50:3000/tempstore).

🍃 MongoDB Atlas Connection

To persist data to your MongoDB Atlas cluster:

  1. Create a free cluster on MongoDB Atlas.
  2. Click Connect > Drivers > copy connection string.
  3. Paste into your .env file:
    MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/neckhofis?retryWrites=true&w=majority
  4. Restart the backend server. The badge above will turn green!

🚀 Deploying to Render

Since your ESP8266 code is configured for neckhofis.onrender.com:

  1. Push this repository to GitHub.
  2. Log in to Render.com and select New Web Service.
  3. Set Build Command: npm install
  4. Set Start Command: npm start
  5. Add Environment Variable: MONGODB_URI
  6. Render will assign your service URL: neckhofis.onrender.com!
